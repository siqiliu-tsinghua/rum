The drain uses `Arc::into_inner`, stops at a shared strong holder, detaches
the link, and immediately drops the acquired node. Its rustdoc records the
premise: production family payloads have no observable destructor, so payload
release order is not a semantic. Adding such a payload requires revisiting
that decision. The helper allocates no worklist and retains at most one
acquired node. Production construction adds no allocation, counter, payload
clone, or conditional branch; observers exist only under `#[cfg(test)]`.
Production nodes still have no `Drop`, so moving their fields remains legal.

Size assessment: the new helper is below 10k characters, including its
explicitly required in-module tests. The derive entry-point file is 14,231
characters (10,535 before its existing test module); a future boundary is the
older traversal/abandon expansion machinery versus macro entry points.
The merge-sort owner is 11,694 characters (11,453 before tests); its future
boundary is persistent index storage versus comparison driving/finalization.
The traversal test file is 29,839 characters; protocol scanning can become a
separate test module. Those unrelated splits are deferred under this brief's
minimal-diff and file-scope rules. The helper is the specifically authorized
new module in the already broad runtime directory; this brief does not
reorganize that directory.

## 3. The certificate

The synthetic payload observer increments active depth on entry, tracks its
maximum, and decrements on exit. Its test-only node destructor transfers any
still-attached link into the payload so releasing that tail nests observers
when the drain is recursive. A correct drain has already detached that link.
Without this instrumentation, ordinary field drop timing could conceal
recursive link destruction behind non-nested payload destructors.

Both exclusive lengths release every node and payload exactly once at depth
1. The shared case releases only the first eight-node prefix, then releases
the second eight-node prefix and the 16-node now-exclusive tail; each phase
has maximum depth 1. A live Weak does not block acquisition or retain the
payload. The wrapper/extraction test also checks size/alignment equality and
preserved ownership.

The mandatory falsifier replaced only the helper's body with `drop(link)`:

```rust
fn drain<N: AccumulatorChainNode>(link: Option<Arc<N>>) {
    drop(link);
}
```
